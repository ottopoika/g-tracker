# Speksi v0.2.0: Omat treenit + aikadata (sovittu 27.10.2026)

1. **Oma treeni**: kootaan vapaasti liikepankista (ohjelma + historia + omat). Ei siirrä ohjelman etenemistä; ohjelma = "Oma", jakso ja viikko tyhjät. Pohjaksi voi valita minkä tahansa aiemman treenin; painot esitäytetään viime kerran tuloksilla.
2. **Liikkeet pankin ulkopuolelta**: vapaa lisäys, sumea haku ja "Tarkoititko…?". Väline: koko nimi on tunniste, rinnalla johdetut kentät perusliike ja valine.
3. **Aikaleimat (taustadata)**: sarjan `kirjattu`, treenin alku/loppu, jälkikirjaus-lippu (< 15 s edellisestä tai valmiin treenin muokkaus). Ei näytetä käyttäjälle.
4. **Palautusajastin (ei-ohjaava)**: kuittauksen jälkeen, ohitettava, jakson `lepo_s` (oma treeni 90 s).

CSV: uudet sarakkeet loppuun: perusliike, valine, treeni_alku, treeni_loppu, jalkikirjaus.
