# Speksi v0.4.0: Keho-näkymä + Tänään-listan korostus (5.11.2026)

## Keho (korvaa Paino-välilehden)
- Tunnuslukuruudut: paino, rasvaprosentti, rasvamassa, lihasmassa (tai luurankolihas, jos viimeisin mittaus antaa sen). Muutos edelliseen mittaukseen + minikäyrä. Väri kertoo suunnan hyvyyden; "eri laite" -merkintä kun laite vaihtui.
- Trendi: mittarivalinta (sirut), kaavio ajan yli, napautus näyttää arvon/päivän/laitteen. Katkoviiva kun laite vaihtuu (paitsi `ver: 1` -mittareilla). Painossa mukana punnitukset.
- Mittauslista: päänäkymässä vain päämittarit; avattuna muut arvot + segmenttitaulukko.
- Lomake vaihteleville tuloksille: vakiokentät, "Lisää arvo" luettelosta, oma mittari (nimi + yksikkö → `meta.omatMittarit`), valinnaiset segmentit.
- Data: `mittaukset`-kokoelma. Vienti `kehonkoostumus_*.csv` pitkänä taulukkona (yksi rivi per arvo).
